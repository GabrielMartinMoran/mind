## mind v1.6.0

Minor release focused on sharper agent memory discipline and a couple of
reliability fixes. Agents now get clearer rules for what to persist as durable
memory, a complete living reference taxonomy, and MCP search is no longer
vulnerable to a fallback bug.

### Highlights

- **Sharper durable-memory guidance** — agents now follow a four-point
  pre-creation checklist (future utility, novelty, evidence, stability) before
  writing a durable memory, reducing noise from session-summary-style content.
- **Living reference taxonomy formalized** — 7 reference types
  (`ref:project-map`, `ref:architecture`, `ref:domain`, `ref:workflow`,
  `ref:style`, `ref:key-decisions`, `ref:known-pitfalls`) with explicit
  creation/update triggers, content format, and 30-day maintenance reviews.
- **MCP `memory_query` no longer crashes on the LIKE fallback** when FTS5
  returns no results.
- **OpenCode session-end automation is ~95% quieter** — the automation plugin
  now only persists a session summary once per session instead of on every idle.

### Changed

- Memory protocol guidance refined: durable memories now require passing a
  four-point checklist (future utility, novelty, evidence, stability) before
  creation.
- Living reference taxonomy formalized with 7 reference types, creation
  triggers, update triggers, content format, and 30-day anti-staleness reviews.

### Fixed

- MCP `memory_query` no longer fails with `no such column: s.name` when FTS5
  returns no results and the LIKE fallback is used.
- OpenCode automation plugin reduced session summary noise by ~95% by
  switching from `session.idle` (20-50 fires/session) to `session.deleted`
  (1 fire/session).

### Upgrade notes

```bash
mind update
```

`mind update` automatically runs the integration refresh for detected agent
integrations (OpenCode, Claude Code, Codex, Cursor, etc.). No manual
`mind setup refresh` is required. After the update, agents will pick up the
new memory protocol guidance automatically through `mind mcp` on the next
`system_instructions` call. Use `--no-refresh-integrations` on `mind update`
if you need to defer the integration refresh.

> **Restart your agentic system after installing** — fully quit and relaunch
> the editor/agent host (OpenCode, Claude Code, Codex, Cursor, etc.) so the
> updated `mind mcp` stdio process and refreshed integration configs are
> re-read from disk. In-session MCP servers keep the previous binary and
> protocol files cached, so a hot reload won't pick up the new guidance
> until the host is restarted.

## mind v1.7.0

Minor release focused on more consistent search, stronger memory continuity,
expanded agent setup, and a substantially refreshed web experience.

### Highlights

- **More predictable search** — boolean operators are uppercase-only; supplied
  searches without informative terms return a typed validation error, while
  punctuated natural-language questions keep useful partial matches.
- **Richer memory continuity** — checkpoint completion is atomic, date filters
  behave consistently across surfaces, and memory links preserve direction and
  labels.
- **Simpler agent setup** — bare `mind setup` configures supported integrations;
  `mind-management` is the canonical protocol skill, and Pi Agent is supported.
- **Updated web experience** — All spaces search, shared filters, improved logs,
  accessible Neural Map navigation, and URL-restored views make memories easier
  to find and maintain.
- **Indicative benchmark result** — Mind scored 86.67% on a 120-question
  LongMemEval-S subset with RAG disabled. This is an indicative raw-score
  comparison, not an official ranking; the published evaluations use different
  sample sizes and answer/judge configurations.

### Search compatibility

- Only uppercase `AND`, `OR`, and `NOT` are boolean operators.
- A supplied query with no informative term now returns a validation error on
  CLI, MCP, and HTTP surfaces. Omitting the search field retains listing
  behavior.
- MCP `memory_query` search responses are compact by default; detailed score
  and method diagnostics require `USE_DEBUGGING_EXPANDED_TOOLS_RESPONSE=true`.

### Upgrade notes

```bash
mind update
```

Mind refreshes detected agent integrations after updating. Restart the agent
host so it reloads the refreshed MCP process and integration files.
